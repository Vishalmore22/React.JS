📌 X Demo – User Verification & Post App

📝 Description:
This is a simple demo web application inspired by X (Twitter), focused on basic user verification and posting functionality. Users can register, log in with validated credentials, and create posts. The project is built to practice authentication logic and basic CRUD operations using a mock backend.

🚀 Features:
    ✅ User Registration with validation
    🔐 Login with credential verification (matches registered user)
    🚫 Prevent duplicate user registration
    📝 Add posts after successful login
    📄 Display user posts
⚙️ How It Works:
    - User signs up → data stored in JSON Server
    - While registering → checks if user already exists
    - User logs in → credentials are verified with stored data
    - After login → user can create and view posts
