HRMS System

A modern HRMS (Human Resource Management System) built using React JS for managing employees, attendance, authentication, and salary processing.

🚀 Features

🔐 Authentication
• User Login & Logout
• Role-Based Authentication
• Protected Routes
• Session Management

👨‍💼 Admin Panel
• Add Employee
• Update Employee Details
• Delete Employee
• View All Employees
• Manage Roles

👨‍💻 Manager Panel
• View Employee List
• Monitor Attendance
• Employee Overview Dashboard
• 🙋 Employee Panel
• View Own Profile
• Daily Check-In / Check-Out
• Attendance History
• Salary Information

⏰ Attendance System
• Employee Check-In
• Employee Check-Out
• Working Hours Calculation
• Late Entry Detection

💰 Salary Management
• Hourly Salary Calculation
• Monthly Salary Processing
• Salary Slip Generation
